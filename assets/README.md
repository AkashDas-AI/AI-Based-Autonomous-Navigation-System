# Assets Directory (`assets/`)

This directory is designated for curated portfolio media, architecture diagrams, and demonstration assets for documentation and presentation purposes.

## Subdirectories

- **`images/`**: High-resolution diagrams, architecture flowcharts, UI screenshots, and curated trajectory visual figures.
- **`videos/`**: Demonstration recordings, screen captures of interactive simulation runs, and visual navigation demos.

## Difference from `outputs/`

- **`assets/`**: Curated, version-controlled media specifically included for documentation, GitHub README presentations, and portfolio showcases.
- **`outputs/`**: Ephemeral, machine-generated artifacts from daily simulation and experiment executions (ignored by Git).
